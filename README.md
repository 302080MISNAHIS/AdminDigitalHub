# MISNAHIS School Website

A responsive static school website built with HTML, CSS, and JavaScript.

## Files
- `index.html` — main website
- `style.css` — design and responsive layout
- `script.js` — mobile navigation and year
- `README.md` — project guide

## Publish with GitHub Pages
1. Create a GitHub repository, e.g. `misnahis-school-website`.
2. Upload all files from this folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide your website address.

## Customize
Replace the sample news cards, add actual school photos, and update the contact/social links before publishing.
